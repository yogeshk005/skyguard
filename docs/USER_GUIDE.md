# User guide

1. Start the backend and frontend as described in [INSTALLATION.md](INSTALLATION.md).
2. Register with an email and a password of at least 10 characters.
3. Create a project. Copy the generated connection command while the one-time token remains visible.
4. Install the agent and run the command against your project root.
5. Refresh the project findings in the dashboard; select a finding to inspect its bounded code context.
6. Change finding status or request optional Gemini analysis after configuring a key.

The current interface does not implement token rotation UI, scan history views, analytics, notifications, or applying fixes. AI suggestions are advisory and are never applied automatically.
